This stage trains a supervised machine learning baseline. It consumes the following artifacts:
\begin{itemize}
\item under \code{models/simulink/*/}:
  \begin{itemize}
  \item \code{tsENV_questions/}
  \end{itemize}
\end{itemize}

\begin{itemize}
\item \code{train_classifier.py}
\end{itemize}

The final artifact is a JSON file inside \code{tsENV_questions/<model>/} that reports the classifier results.
For each seed, it trains two algorithms: one with only the train samples, and another with all samples. It writes the accuracy and the retrieval per class JSON.
The baselines are:
random, majority, nearest-neighbor/DTW, supervised feature-based classifiers, simple physics-inspired rules, 

The classifier for each row slug provides three entries for the different noise levels.
